Here you can find documentation on the user settings, which are the settings available to a normal user, in their settings tab.

## Show Clock

Whether to show a clock in the top right of the web-UI.

## Locale

This setting is for formatting times and dates according to the format used in the set county. It's advised to set the value to the country that you live in.

## Default Notification Service

The notification service that should be selected by default when creating a new reminder.

## Edit Account

The 'Edit Account' button opens a window where you can change the username or password of your account. It's also the place where you can set up MFA. The Apprise URL that you enter for MFA will be used to send the MFA code when trying to log into the account.
